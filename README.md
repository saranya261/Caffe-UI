## 🫖 Today's Brew

| | |
|---|---|
| **Roast** | Plain HTML, CSS and JavaScript |
| **Served** | Static, front-end only |
| **Strength** | 0 frameworks · 0 dependencies · 0 build steps |
| **Backend** | None. Just a good cup and a good page |
| **Best enjoyed** | On any screen, from phone to widescreen |

> **A friendly note:** Sara Nivas is a **simple front-end project**. It is a static website with no backend, no database and no server-side code. The newsletter form and the **+** buttons are for show: they react on the page, but nothing is sent or saved anywhere.

## 🍂 The Menu *(what's inside)*

**☕ Classic Latte** — *Rich. Smooth. Timeless.*
A hero with a looping latte-art video playing quietly behind the headline.

**🧊 Iced Vanilla** — *Cool. Creamy. Refreshing.*
A "Watch Our Story" pop-up that plays the full video with sound.

**🥑 Avocado Toast** — *Fresh. Wholesome. Delicious.*
Seasonal favourite cards with real photos, soft gradients and tappable add buttons.

**🥐 Almond Croissant** — *Buttery. Flaky. Irresistible.*
A story section, a values strip with hand-drawn style line icons, and a newsletter footer.

*Served with:* a mobile menu, keyboard-friendly focus styles, and respect for reduced-motion settings.

## 🚀 Pour Your First Cup

No installing. No terminal. No waiting.

1. **Download** or clone this repo
   ```bash
   git clone https://github.com/<your-username>/sara-nivas-coffee.git
   ```
2. **Open** `index.html` in your browser
3. **Sip.** That's it ☕

*Tip: if the video stays still in a small editor preview, open the page in Chrome. It plays there.*

## 🎨 Make It Your Own

| Want to change... | Look here |
|---|---|
| Drink names, prices, descriptions | the `.card` blocks in `index.html` |
| Colours (cream, espresso, caramel) | the `:root` variables at the top of `phoenix-pro.css` |
| Fonts | the Google Fonts link in `index.html` + `--serif` / `--sans` in the CSS |
| Photos | swap the image files, keep the same names |
| Hero video | replace `coffee.mp4` |

## 🌐 Serve It To The World *(GitHub Pages)*

1. Push this project to GitHub
2. Open **Settings → Pages**
3. Choose **Deploy from a branch** → `main` → `/ (root)` → **Save**
4. In a minute or two it's live at
   `https://<your-username>.github.io/sara-nivas-coffee/`
